# Terraform差分レビュー

以下の観点でTerraformの差分をレビューしてください:

## レビュー観点

### 1. 状態管理
- ステートファイルへの影響を確認してください
- リソースのインポート・移動が適切に行われているか

### 2. 破壊的変更の検出
- リソース再作成が必要な変更（`force_new`）の有無を確認
- 再作成によるダウンタイムやデータ損失のリスクを評価
- 本番環境への影響を考慮した段階的な適用計画を提案

### 3. 権限設定
- IAMロール・ポリシーの権限が最小権限の原則に従っているか
- 過剰な権限付与がないか確認
- セキュリティグループのルールが適切に制限されているか

### 4. リソース依存関係
- `depends_on` の使用が適切か
- リソース間の暗黙的な依存関係に矛盾がないか
- リソース作成・削除順序が正しいか

### 5. 命名規則とタグ
- リソース名が命名規則に従っているか
- 必須タグ（環境、プロジェクト、オーナーなど）が設定されているか

### 6. パフォーマンスとコスト
- インスタンスタイプやストレージサイズが適切か
- コスト最適化の観点から改善提案

## 出力形式

指摘事項がある場合は、以下の形式で記載してください：

**[カテゴリ] 指摘内容**
- 問題点の詳細
- 影響範囲
- 推奨される対応策

問題がない場合は「問題なし」と記載してください。
